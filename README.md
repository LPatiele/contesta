# Contesta — site institucional

Site estático, sem instalação de dependências. Abra index.html no navegador para conferir.

## Publicar no GitHub Pages

1. Na sua conta GitHub, crie um repositório público chamado `contesta`.
2. Em **Add file → Upload files**, envie o conteúdo desta pasta: index.html, style.css, script.js e a pasta assets. O index.html deve ficar na raiz do repositório.
3. Salve em **Commit changes**.
4. Abra **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em **Save**.
5. Aguarde a publicação. O endereço será informado nessa tela, normalmente https://SEU-USUARIO.github.io/contesta/.
6. Antes de imprimir o cartão, abra esse endereço no celular e teste os botões do WhatsApp. Gere o QR code somente depois de confirmar o endereço definitivo.

Guia oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Conteúdo

Os textos e valores estão em index.html; as cores e estilos em style.css. O WhatsApp com código do Brasil está em script.js e também nos links do HTML como alternativa sem JavaScript.

Não há formulário, rastreamento ou cookies próprios. Ao clicar no WhatsApp o visitante segue para um serviço externo. O agendamento é combinado na conversa, sem promessa de disponibilidade automática.

O PDF original não foi incluído no site. O exemplo de diagnóstico usa somente uma síntese sem dados pessoais, sem apresentar oportunidades como resultados comprovados.
